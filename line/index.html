01 · The idea

Linear is linear.

Linear is where software teams keep every task: bugs, requests, ideas. Each one moves in a straight line from Todo to Done. So the whole ad is one line of light. It puts the chaos in order, carries the work, empties the backlog and, at the end, becomes the logo, which is itself made of lines.

To make people care, the story follows one task: Maya, a customer who can't log in. Her message is lost in the noise, the line picks it up, an agent fixes it, and she's back in.

00:01 · master prompt · claude code
Build a 27-second vertical spec ad for Linear called "One line." in Remotion (React), 1080x1920 at 30 fps. The idea: Linear is linear. A pile of messy tasks becomes ONE line, the work moves along that line from Todo to Done, and in the end the line becomes the logo. Tell it through one person: Maya, a customer who can't log in. Draw everything on a single canvas 2D, make every value a function of the current frame, and keep one continuous movement with no hard cuts.

Look: Linear's near-black app (#08090A, panels #151618, hairlines at 14% white), indigo #5E6AD2 and accent #7170FF / #828FFF, yellow #F2C94C for In Progress, Inter for everything and Commit Mono for IDs. The official Linear logo (untouched SVG) sits small in the top-right corner of every scene, inside the issue card, in the ⌘K menu and on the agent chip, and closes the ad as the full wordmark.

Scenes, in order:
1. 0-3.7s: "214 tasks. Zero order." About 58 floating pieces (issue cards, chat bubbles like "still broken", red badges) drifting and tilted, some blurred for depth. Maya's message glows among them: "Can't log in. Again. 😩".
2. 3.7-7.3s: "One line. Everything in order." A line of light draws down the left side (x 150). Each piece joins the line when the line reaches its height (start = 3.6 + 0.8 · (y − 560) / 1160); four become a clean list to the right of the line, the rest are absorbed. Maya's message turns into the issue ENG-2117 "Maya can't log in".
3. 7.3-10.5s: "One command. Handed to an agent." A ⌘K menu types "Delegate" and selects "Delegate to agent…"; an "Agent" chip with the Linear icon flies onto Maya's card.
4. 10.5-15.9s: "Todo → Done. Along one line." then "Maya's bug. Done." The line becomes a track with Todo, In Progress and Done stations; Maya's card travels down it and lands on Done with a flash. Labels never get covered.
5. 15.9-20s: a big counter headline "214 open." that counts down to "0 open." while a river of task cards rushes down the line into Done, faster and faster.
6. 20-22.4s: "Maya's back in." Her thread: her complaint (dimmed), the team replies "Fixed ✓ Try again.", she answers "It works! 🙌".
7. 22.4-27s: the thread fades, the same line tilts to 45°, moves to the center and multiplies into 44 full-screen stripes that close into a circle: the official Linear logo, which grows into the wordmark with "Designed for speed."

Add a light 3D tilt (CSS perspective) to the middle section and sparks that run down the line, so it never looks flat. Keep every headline, card and logo inside x 90-960 and y 250-1480, and something already moving on frame 0.

Audio: an original track made in code (numpy). It starts as a cloud of detuned notification pings; when the line arrives everything locks into one straight pulse (round sine bass in eighth notes, a soft pad in D, a gentle kick), builds with the river of tasks and stops on "0 open", keeps only the pad under Maya's thread and resolves on a chord of the same pad when the logo forms. One soft sound per event (keep the highs gentle, nothing harsh): the pop of Maya's message, the zip of the line, a tuned click for each task that joins, low-profile keys for ⌘K, a whoosh for the agent chip, a low chime on Done, rising ticks for the countdown, chat pops, a whoosh as the line turns into stripes and a deep soft bloom on the logo. Narration with Kokoro TTS (voice am_michael): "Two hundred fourteen tasks. Zero order." / "Linear puts it all on one line." / "One command hands Maya's bug to an agent." / "To do. In progress. Done." / "Then the rest. All of it." / "And Maya's back in." / "Linear. Designed for speed." Check every line with Whisper. Master to -14 LUFS with a true peak at or below -1.5 dB, and check the momentary loudness so no moment jumps out.

Process: export a strip of stills every 1.5 seconds (including frame 0) with the safe zone marked. Wait for my approval before the final render.

What came back: one Remotion composition on a single canvas: the floating pieces, the line and its sparks, the list, the track, the river of tasks and the stripes of the logo, with the ⌘K menu and Maya's thread in plain HTML on top.

05 · What Claude built

One line, start to finish.

ORDER

Tasks join when the line reaches them

Each piece has a start time from its height on screen, so the top joins first and the bottom last, and the order feels physical.

STORY

One task to follow

Maya's message becomes ENG-2117, gets an agent, travels Todo → In Progress → Done and comes back as "It works! 🙌".

MUSIC

Composed in code

Noise that locks into one straight pulse, builds with the river of tasks, stops on "0 open" and resolves on the logo with the same pad, so the ending never sounds pasted on.

VOICE

Kokoro TTS, checked by Whisper

Seven short lines in the Michael voice, each one landing on its headline. Mix at −14 LUFS, true peak −2.1 dB.

key code · TypeScript
// each task joins the line when the line reaches its height
const startOf = (y: number) => 3.6 + 0.8 * Math.max(0, Math.min(1, (y - 560) / 1160));
const u = k(t, startOf(it.y), startOf(it.y) + 0.75, io);
const x = lerp(it.x + drift, LX, u);                 // pulled into the line

// the end: the same line tilts and multiplies into the 44 stripes of the logo
c.translate(lerp(LX, 540, u), lerp(1140, 840, u));
c.rotate(lerp(-Math.PI / 2, -Math.PI / 4, u));
for (let i = 0; i < 44; i++) {
  const d = (i - 21.5) * 46 * u, slide = u * (hash(i) - 0.5) * 900;
  line(-half + slide, d, half + slide, d);
}

07 · Watch out

What to check before you render.

A line that cuts words

A bright line running through a list slices the text. Put the line beside the list, not through it.

Labels under moving cards

Fast cards can cover the station names. Draw the labels last, on their own dark background.

An ending from another video

A brighter, louder chord at the logo makes the end sound pasted on. Measure the loudness second by second and resolve with the same sound the music already uses.

Harsh highs

High chimes with a sharp attack sound strident on phones. Keep them lower, give them a soft attack and low-pass the effects.

08 · Ship it

From render to post.

Step 01

Export at a real bitrate.

A dark, flat background compresses to almost nothing. Re-encode at a constant 14 Mbps with the command below.

Step 02

Check the loudness.

Aim for −14 LUFS with a true peak at or below −1.5 dB, and no moment much louder than the rest.

Step 03

Make the cover.

The profile grid crops covers to 3:4, so keep the logo and the brand name between y 300 and 1480.

Step 04

Caption.

Short and clear, and end with "Inspired by @[brand]".

export · ffmpeg
ffmpeg -i render.mp4 -i mix.wav -map 0:v -map 1:a -c:v libx264 -preset slow -b:v 14M -minrate 14M -maxrate 14M -bufsize 7M -x264-params nal-hrd=cbr -pix_fmt yuv420p -af "aresample=192000,alimiter=limit=0.78:level=false,aresample=48000" -c:a aac -b:a 320k -movflags +faststart final.mp4
check loudness · ffmpeg
ffmpeg -i final.mp4 -af ebur128=peak=true -f null -
