01 · The idea

One line, a whole payment.

Payment ads usually show a phone, a card and a smile. Stripe's difference lives in the code: a few lines replace a whole payments team. So that became the rhythm of the ad. Each block opens with one real line of the Stripe API typing in at the top, and the scene below is what that line does.

It is a spec piece built by the Lab. Stripe's brand page doesn't allow its logo in ads, so the name appears only as plain type and no logo is drawn anywhere.

02 · References

What Claude needed before the first prompt.

Fintech and developer tools are among the most requested launches made with Claude. The references were Stripe's own site (the moving mesh gradient, crisp product UI, code next to the result) and the most-watched API promos on prompt-motion.com: code cards, counters and currency swaps.

One rhythm, many techniques

03 · One-time setup

Before the prompt.

Step 01

Install Claude Code.

Follow the official guide at docs.claude.com (Claude Code overview) for your system.

Step 02

Install Node 22+ and FFmpeg.

Start a Remotion project with npx create-video@latest and open Claude Code inside that folder. The shaders are plain WebGL2 in a canvas, no extra library needed.

Step 03

Keep the fonts local.

Download the woff2 files into public/ and load them with FontFace. Google Fonts can fail in the middle of a render and swap your type for a fallback.

Step 04

Python for the sound.

numpy and scipy compose the music and SFX. Kokoro TTS reads the narration and faster-whisper checks it; if they won't install, ask Claude for the lines as separate files and use any TTS.

05 · What Claude built

An ad that runs like an API.

CARD

Metal, not a picture

For each pixel, a ray hits a rounded slab. Brushed lines bend its normal, an anisotropic highlight stretches across it, and it reflects the gradient. The print is a canvas texture laid on top.

GRADIENT

Noise you can touch

Three layers of simplex noise mix the palette, a height field shades it like silk, and the tap sends two ripples through it that interfere like real waves.

MUSIC

Composed in code

Glass-like electronica in A-flat major at 120 BPM: FM bells with a ping-pong delay, a round sub, dry claps and fine hats. It darkens to F minor on the fraud scene.

VOICE

Kokoro TTS, checked by Whisper

Nine short lines in the Heart voice. "Any card." came out sounding like a question, so it became "It takes any card." Mix at −14 LUFS, true peak −2.1 dB.

key code · GLSL
// the card: a rounded slab ray-traced per pixel, brushed metal
float ward = exp(-((ht*ht)/(0.42*0.42) + (hbv*hbv)/(0.07*0.07)) / (hn*hn));
float F = 0.62 + 0.38*pow(1.0 - max(dot(Nc,V),0.0), 5.0);
vec3 metal = acc*base*1.05*F + vec3(1.0,0.96,1.0)*ward*0.8;

// the gradient: three layers of simplex noise mixing the palette
float n1 = snoise(vec3(q*0.85 + vec2(0.0, t*0.05), t*0.11));
float n2 = snoise(vec3(q*1.5 + vec2(3.0, -t*0.07), t*0.14 + 5.0));

08 · Watch out

What to check before you render.

Metal that reads as plastic

Dark base color plus a weak reflection looks like black plastic. Raise the base, reflect a bright environment and make the brushed lines visible.

Blocks that start empty

If the form only appears after the code finishes, the first frame of the block is empty. Show a skeleton of the result from frame 0.

Objects over the number

A 3D ring in front of a big number hides it. Tilt the ring so it passes behind the number and only crosses it at the edges.

Fonts that vanish

A web font request can fail mid-render and silently fall back. Load local files and wait for them before drawing on canvases.

Clips that cross a cut

In the how-it-was-made video, each clip has to start at the beginning of its scene, or it runs into the next scene halfway through.

09 · Ship it

From render to post.

The render is not the finish line. These four steps decide how the piece looks once Instagram compresses it.

Step 01

Export at a real bitrate.

Smooth gradients band when compressed. Re-encode at a constant 14 Mbps with the command below.

Step 02

Check the loudness.

Aim for −14 LUFS with a true peak at or below −1.5 dB. The command limits the audio before encoding.

Step 03

Make the cover.

Use the most striking frame. The profile grid crops covers to 3:4 (the middle 1080×1440), so keep the hero between y 240 and 1680.

Step 04

Caption with the disclaimer.

A spec ad says so. End the caption with "Spec ad · not commissioned by [brand]. Inspired by [brand]." plus the trademark notice.

export · ffmpeg
ffmpeg -i render.mp4 -i mix.wav -map 0:v -map 1:a -c:v libx264 -preset slow -b:v 14M -minrate 14M -maxrate 14M -bufsize 14M -x264-params nal-hrd=cbr -pix_fmt yuv420p -af "aresample=192000,alimiter=limit=0.78:level=false,aresample=48000" -c:a aac -b:a 320k -movflags +faststart final.mp4
check loudness · ffmpeg
ffmpeg -i final.mp4 -af ebur128=peak=true -f null -
