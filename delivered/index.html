00 · Version 5 · the one we published

One world, one box.

Version 4 was two videos cut together, and it showed: one box was sealed, then a different box was sealed again. Version 5 rebuilds the whole spot as one creation: the same box goes from the screen to the door, and the camera never jumps to another world.

01 · The idea

From your screen to your door, in one take.

The promise of Amazon is that one tap sets everything in motion. So the products literally leave the phone and land in the box, and that box never changes: sealed, labeled, scanned, carried by a drone over the city and dropped at your door. While it flies, the app tracks it live, and you see what the drone sees.

03 · One-time setup

Before the prompt.

Step 01

Install Claude Code.

Follow the official guide at docs.claude.com (Claude Code overview) for your system.

Step 02

Install Node 22+ and FFmpeg.

Start a Remotion project with npx create-video@latest, add @remotion/three, three, @react-three/fiber and @react-three/drei, and open Claude Code inside that folder.

Step 03

Python for the sound.

numpy and scipy compose the music and SFX. Kokoro TTS reads the narration; if it won't install on your machine, ask Claude for the lines as separate files and use any TTS.

Step 04

A GPU-friendly render.

3D renders through Chrome. Pass --gl=angle to every render and still command, or the canvas comes out black.

05 · What Claude built

Two cameras, one world.

THE APP

A canvas on a 3D phone

The Amazon screens are drawn in 2D every frame and used as the iPhone's screen texture, with exact colors and a glass layer that reflects the scene.

THE BOX

One box, start to end

Flaps on hinges, a crumpled paper mesh inside, tape that grows and folds down, a label that lands. The same object rides the belt, hangs from the drone and lands at the door.

THE DRONE CAM

The scene, drawn twice

Every frame, the same 3D world is rendered a second time from a camera under the drone into a texture: that is the LIVE window.

THE PACE

Faster without cuts

Video time is mapped to scene time per section, so each part speeds up smoothly and nothing jumps.

key code · three.js + Remotion
// 1 · the Amazon app is a 2D canvas redrawn every frame and used as the iPhone's screen
drawApp(ctx, t, logo, font);         // cart 1 → 2, "2 items" sheet, "Order placed"
screenTexture.needsUpdate = true;    // CanvasTexture on the phone's screen mesh

// 2 · the live drone cam: the same scene, drawn a second time per frame from the drone
useFrame(({gl, scene}) => {
  droneCam.position.copy(dronePos).add(forward.multiplyScalar(1.15)).add(down(0.6));
  gl.setRenderTarget(fbo); gl.render(scene, droneCam); gl.setRenderTarget(null);
});                                  // fbo.texture → the rounded LIVE window

// 3 · faster without cuts: video time → scene time, per section
const FAST_NEW = [0, 4.0, 4.3, 5.3, 6.6, 9.6, 11.0, 11.9, 13.7, 15.4, 16.6, 19.9, 23.5];
const FAST_OLD = [0, 4.5, 4.8, 7.0, 8.35, 12.4, 14.3, 15.6, 17.6, 20.2, 21.3, 25.2, 28.8];
const t = interpolate(frame / 30, FAST_NEW, FAST_OLD);

07 · Decisions

Where the taste is.

01

One creation, not two cuts

Two good takes glued together still look like two videos. One world and one object make it feel made on purpose.

02

The brand, never repeated the same way

Smile on the front, the "a" on the sides, "amazon" on top of the drone, "prime air" below the rotors: always visible, never wallpaper.

03

Show the 2 items

A tiny cart badge was not enough. A big counter that jumps and a "Your cart · 2 items" sheet make it obvious.

04

Layers that don't fight

The phone is not flying, so it sits on brand blue, and the city lives only inside the drone's camera.

05

The best box we already had

We copied the packing shot people liked frame by frame (angle, paper, tape, label) instead of inventing a new one.

06

Fast, not rushed

From 30 to 23.5 seconds by speeding up each section, never by cutting text below 1.5 seconds.

08 · Watch out

What to check before you render.

A scene that mounts late

Remotion's ThreeCanvas only draws when the frame changes. If your scene waits for fonts or images, force a draw when it mounts or the still comes out empty.

Things glued to the camera

Move the camera in a layout effect, not during render, or a phone attached to it can be drawn with the previous frame's camera.

Screens look washed out

A lit screen under ACES tone mapping goes grey. Draw the screen unlit with a little gain and put a reflective glass layer on top.

Brand orange turns yellow

Very bright emissive orange becomes pale yellow after tone mapping. Keep it near 1.0.

Voice and pace

When the spot gets shorter, the narration has to lose lines too. Cut the ones the screen already says.

09 · Ship it

From render to post.

The render is not the finish line. These four steps decide how the piece looks once Instagram compresses it.

Step 01

Export at a real bitrate.

Instagram compresses again, so re-encode at a constant 14 Mbps with the command below.

Step 02

Check the loudness.

Aim for −14 LUFS with a true peak at or below −1.5 dB. The AAC encoder can push peaks up, so the command limits the audio before encoding.

Step 03

Make the cover.

Use the frame that shows the product best. The profile grid crops covers to 3:4 (the middle 1080×1440), so keep the hero between y 240 and 1680.

Step 04

Caption, short.

End the caption with one line: "Inspired by @brand". No long disclaimers.

export · ffmpeg
ffmpeg -i render.mp4 -i mix.wav -map 0:v -map 1:a -c:v libx264 -preset slow -b:v 14M -minrate 14M -maxrate 14M -bufsize 28M -x264-params nal-hrd=cbr -pix_fmt yuv420p -af "alimiter=limit=0.8:level=false" -c:a aac -b:a 320k -movflags +faststart final.mp4
check loudness · ffmpeg
ffmpeg -i final.mp4 -af ebur128=peak=true -f null -

Before you post: everything inside x 90–960 and y 250–1480 · no text on screen for less than 1.5 s · something moves on frame 0 · −14 LUFS · 12–16 Mbps · "Inspired by @brand" in the caption.
