01 · The idea

Don't tell it. Let the voice do it.

The first version was a story in a room at midnight. It looked static and it only talked about the voice. So the room went away. Now there is one night sky and one orb that is the voice, and every block is a feature you can hear: the pause is a real silence, the slow line is really slower, the whisper is a whisper and the Spanish line is the same voice in Spanish.

It is a spec piece built by the Lab. There is no footage, screen recording or logo file: the orb, the app cards and the wordmark are drawn in code.

02 · References

What Claude checked before the first prompt.

A feature only counts if the app really has it. Before writing a line, a separate agent checked the ElevenLabs docs.

Pauses on Eleven v4

SSML <break> tags do not work on the v3/v4 models. The docs point to audio tags such as [long pause], plus ellipses. The silence you hear is the model's, measured at 1.3 s.

Speed

Speed lives in the voice settings and goes from 0.7 to 1.2. The docs disagree on whether v4 has it, so the slow line was generated on Multilingual v2, where it is documented, at 0.80.

Audio tags

[whispers] goes in the text, before the line it changes. The docs warn tags are not always followed exactly, so the voice was tested before animating anything.

Same voice in Spanish

Any ElevenLabs voice can speak other supported languages; a non-native voice may keep some accent. It was checked by ear before building.

03 · One-time setup

Before the prompt.

Step 01

Install Claude Code.

Follow the official guide at docs.claude.com (Claude Code overview) for your system, and open it inside an empty project folder.

Step 02

A way to render a canvas to video.

Any setup that draws an HTML canvas as a pure function of time and captures it frame by frame works, for example Remotion (npx create-video@latest) or a headless browser piping frames into FFmpeg. Install Node 22+ and FFmpeg.

Step 03

An ElevenLabs API key.

Create a key in your ElevenLabs account and keep it in an environment variable, never in the code. Use the with-timestamps endpoint so every word comes back with its start and end time.

Step 04

Python for the checks.

Pillow builds the contact sheets, Whisper (faster-whisper) checks that the audio tags were not read out loud, and FFmpeg measures the silence and the loudness.

a world that stops in the silence · javascript
// the world clock: it STOPS in the real silence and runs slower in the slow and whispered lines,
// so the dust, the ring and the orb literally hold their breath with the voice
const RATES = [[T_PAUSE0 + 0.1, T_PAUSE1 - 0.05, 0], [T_SLOW0, T_SLOW1, 0.6], [T_WH0, T_WH1, 0.75]];
function worldClock(t) {
  let c = t;
  for (const [a, b, r] of RATES) c -= Math.max(0, Math.min(t, b) - a) * (1 - r);
  return c;
}
// how loud the voice is right now (0..1), straight from the word timestamps
function speak(t) {
  let v = 0;
  for (const w of WORDS) {
    if (t < w.s - 0.08 || t > w.e + 0.18) continue;
    v = Math.max(v, Math.min(clamp((t - (w.s - 0.08)) / 0.08), clamp(((w.e + 0.18) - t) / 0.18)));
  }
  return v;
}
the ring of sound bars · javascript
// the ring of sound bars around the orb: amp = the voice, sx = stretched (slow line), almost flat in the pause
function voiceRing(K, cx, cy, r, wc, o = {}) {
  const n = o.n || 100, amp = o.amp ?? 1, sx = o.sx || 1;
  for (let i = 0; i < n; i++) {
    const a = i / n * TAU;
    const v = Math.abs(noise1(i * 0.31 + wc * 3.2)) * (0.55 + 0.45 * Math.sin(i * 0.43 + wc * 2.1));
    const h = 6 + 124 * v * amp, r0 = r + 20;
    K.beginPath();
    K.moveTo(cx + Math.cos(a) * r0 * sx, cy + Math.sin(a) * r0);
    K.lineTo(cx + Math.cos(a) * (r0 + h) * sx, cy + Math.sin(a) * (r0 + h));
    K.stroke();
  }
}
