01 · The idea

Five cursors, one canvas.

Design-tool ads usually show a screen recording of one person working. Here the idea is what makes Figma Figma: many people on the same canvas at once. So five colored cursors with names are the cast, and they build the ad live in front of you, one feature and one technique every 3 seconds.

It is a spec piece built by the Lab. Figma's brand rules allow its logo to identify Figma but not to modify it, so the logo is the official lockup, flat and untouched, and the shapes in the ad are basic geometry, not pieces of the logo.

02 · References

What Claude needed before the first prompt.

Launch films for design and developer tools are what gets watched and commissioned the most when made with Claude. The references were geometric posters that break their own frame and UI that morphs from one state into another.

One cast, many techniques

A pen curve turned into a 3D tube, a CSS 3D grid of 120 cards, a poster with selection boxes, a camera on a spline, an SDF shader, a CSS card flip and a 2D canvas wall. All of them driven by the cursors.

Brand rules

Use the official files from figma.com/using-the-figma-brand, never modify or combine the logo, and don't imply that Figma sponsors the piece. The caption carries the spec-ad disclaimer.

Palette

The light canvas, the selection blue and the five logo colors.

Type

Inter 800 for headlines and UI, JetBrains Mono for code and labels.

Pace

One scene and one headline about every 3 seconds, the cursors already on the canvas on frame 0, every headline on screen for at least 1.5 seconds.

Format

9:16, 24 s, 30 fps, with every headline, screen and shape that matters inside the Reels safe zone.

Sound

Funk made in code and one sound per event: pen clicks, pops, zips, boings.

03 · One-time setup

Before the prompt.

Step 01

Install Claude Code.

Follow the official guide at docs.claude.com (Claude Code overview) for your system.

Step 02

Install Node 22+ and FFmpeg.

Start a Remotion project with npx create-video@latest, add @remotion/three, three, @react-three/fiber and @react-three/drei, and open Claude Code inside that folder.

Step 03

Python for the sound.

numpy and scipy compose the music and SFX. Kokoro TTS reads the narration and faster-whisper checks it; if they won't install, ask Claude for the lines as separate files and use any TTS.

Step 04

A GPU-friendly render.

The 3D scenes render through Chrome. Pass --gl=angle to every render and still command, or the canvas comes out black.

00:01 · master prompt · claude code
Build a 24-second vertical spec ad for Figma called "Multiplayer" in Remotion (React), 1080x1920 at 30 fps. The idea: Figma's signature is multiplayer, everyone designing on the same canvas at once. So five colored cursors with names (Ana, Leo, Mia, Kai, Sam) build the whole ad live on the canvas. One new technique every 3 seconds. Look: Figma's light canvas (#F5F5F5) with a dot grid, the selection blue (#0D99FF) for handles and selection boxes, and the five logo colors (#FF3737, #FF7237, #874FFF, #00B6FF, #24CB71). Headlines in Inter 800 with the second line in a logo color, code in JetBrains Mono. Cursors are the Figma arrow in a person's color with a rounded name tag. Use the official logo files from figma.com/using-the-figma-brand and never modify them: the lockup stays flat at the end.

Scenes, in order:
1. 0-3s: the cursors are already on the canvas on frame 0. Mia uses the pen tool: she clicks three anchor points and the curve draws with blue handles, then the curve lifts off the canvas into a glossy 3D ribbon (TubeGeometry along the same curve, vertex colors running through the five logo colors) while the camera swings around it. 8. 21-24s: the official Figma lockup, flat, with the five cursors gathering around it, and "Nothing great is made alone."

05 · What Claude built

An ad that behaves like the product.

RIBBON

A curve that becomes a tube

The same two Bézier segments drawn by the pen are sampled into points, lifted off the canvas with a sine wave and turned into a TubeGeometry with vertex colors running through the logo palette.

RIPPLE

Delay by distance

Each of the 120 cards changes when the time since the click passes its distance to the main component times 0.06 seconds, so the change travels like a wave.

MUSIC

Composed in code

Funk in A mixolydian at 120 BPM: a clavinet in sixteenths, a slap bass with pops, kick, snare with ghost notes and a tambourine, joining in layers.

VOICE

Kokoro TTS, checked by Whisper

Eight short lines in the Heart voice, all heard correctly on the first pass. Mix at −14 LUFS, true peak −2.1 dB.

08 · Watch out

What to check before you render.

An empty frame 0

Cursors that fly in from outside leave the first frame empty. Start them already on the canvas and the curve already started.

White text on white screens

With the camera close, the headline lands on white phone screens. Pull the camera back and frame the screens below the headline.

A shape that overflows 9:16

A full-screen SDF shader written for a square frame overflows a vertical one. Scale the coordinates by the aspect ratio before drawing the shape.

Headlines over busy color

Over a wall of colorful frames the headline disappears. Draw a light band behind it.

Clips that cross a cut

In the how-it-was-made video, each clip has to start at the beginning of its scene, or it runs into the next scene halfway through.

09 · Ship it

From render to post.

The render is not the finish line. These four steps decide how the piece looks once Instagram compresses it.

Step 01

Export at a real bitrate.

Flat color fields and fine dot grids band when compressed. Re-encode at a constant 14 Mbps with the command below.

Step 02

Check the loudness.

Aim for −14 LUFS with a true peak at or below −1.5 dB. The command limits the audio before encoding.

Step 03

Make the cover.

Use the frame that shows the brand best. The profile grid crops covers to 3:4 (the middle 1080×1440), so keep the hero between y 240 and 1680.

Step 04

Caption with the disclaimer.

A spec ad says so. End the caption with "Spec ad · not commissioned by [brand]. Inspired by [brand]."

export · ffmpeg
ffmpeg -i render.mp4 -i mix.wav -map 0:v -map 1:a -c:v libx264 -preset slow -b:v 14M -minrate 14M -maxrate 14M -bufsize 14M -x264-params nal-hrd=cbr -pix_fmt yuv420p -af "aresample=192000,alimiter=limit=0.78:level=false,aresample=48000" -c:a aac -b:a 320k -movflags +faststart final.mp4
check loudness · ffmpeg
ffmpeg -i final.mp4 -af ebur128=peak=true -f null -
